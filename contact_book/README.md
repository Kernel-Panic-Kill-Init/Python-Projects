# Contact Book (Python)

A simple console-based contact book written in Python.  
The app lets you add, view, edit, delete, and list contacts stored in a dictionary.

## Features

- `add_contact(contact_book)` – add a new contact (name, phone, email, address).
- `view_contact(contact_book)` – display details for a single contact.
- `edit_contact(contact_book)` – update an existing contact.
- `delete_contact(contact_book)` – remove a contact by name.
- `list_all_contacts(contact_book)` – print all contacts or a message when the book is empty.
- `display_menu()` – show the menu options.

## Tech stack

- Python 3.x
- Core concepts: functions, conditionals, loops, dictionaries.

## How to run

python contact_book.py
